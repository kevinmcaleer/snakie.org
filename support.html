Support the project

Snakie is free and open source. You can help keep it that way.

Snakie is built in the open by one developer, in evenings and weekends, and given away for nothing. If it's useful to you, there are a few ways to help it keep growing. Some cost a coffee, some cost nothing at all.

Fund development

Every contribution goes straight into time spent building Snakie: new instruments, more parts, and support for more boards.

The quickest way to say thanks: a one-off tip, or a small monthly membership. No account needed, and it directly funds the hours that go into new features.

Help for free

Not everything helpful costs money. These make a real difference too.

  • Star the repo — a GitHub star boosts visibility and helps more people find Snakie.
  • Report bugs — use the in-app Report a bug panel, or open an issue. Clear reports make Snakie better for everyone.
  • Contribute a part — add a board or component to the parts library and share it with the community.
  • Spread the word — tell a friend, post a project you built, or share Snakie with your makerspace or class.
  • Suggest features — open a discussion with ideas for instruments, parts or boards.
  • Read the docs — everything you need is at docs.snakie.org.
  • Improve the docs — fix a typo or clarify a guide; the docs live in the snakie-docs repo and small PRs are very welcome.

Thank you for supporting Snakie 💚

Every coffee, sponsorship and star keeps the project moving.
