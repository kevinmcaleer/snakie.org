Snakie 0.25.0 is here, and it's all about one thing: making robots **move** with as little friction as possible. From cleaner code on the board to posing your robot with a slider, this release shortens the road from "wired up" to "watch it wiggle."

Here's what's new.

**A friendly `snakie` module.** Board code just got tidier. Instead of hunting for the right imports, write:

```python
from snakie import Servo, Buzzer, Led, Pin, PWM
```

One clear, collision-proof name for the hardware you actually plug in — no more clashes with a vendor `servo` module hiding on your firmware.

**The Poses bench.** A brand-new instrument that works like a live servo test bench. Press a saved pose or drag a per-servo slider and the 3-D model moves **instantly** — no program required — gliding smoothly from one pose to the next. It's the fastest way to check a joint is set up right before you commit any code.

**Bind a breadboard servo to a 3-D joint.** Wire a servo in the Board View, then tell it which joint it drives — from either the Board View or the Robot View. Now when your running program moves that servo, the matching joint in the 3-D model moves right along with it, live.

**Motion Studio.** Author motion the way you actually think about it: save **poses**, chain them into **sequences** for walk cycles (with per-step timing and easing), and build **puppet controls** — a single slider that blends between poses. When you're happy, export it all as plain, readable MicroPython you can run and tweak by hand.

**Servos accept a PWM.** The servo driver now takes a `PWM` you built yourself, so your setup reads exactly how it's wired: pin → PWM → Servo → joint.

## Get it

Grab the latest build from the [GitHub releases page](https://github.com/kevinmcaleer/Snakie/releases), and dive into the full guides and reference over at [docs.snakie.org](https://docs.snakie.org).

Happy building — and this time, happy *moving*. 🤖
