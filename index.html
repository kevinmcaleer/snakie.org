Start with blocks or start with Python, wire the circuit on a breadboard, assemble the robot in 3-D, and watch it all run on live instruments. No board yet? What's inside

Everything between “I have a Pico” and “my robot walks”.

Autocomplete that knows MicroPythonNEW

Completions, parameter hints and hover docs from the official MicroPython stubs. Snakie follows your file, so led. after Pin(…) offers toggle, and port-only calls are labelled.

Blocks and Python, side by sideNEW

Snap blocks together and read the MicroPython they write beside them. Snakie also reads your existing Python back into blocks, so nobody gets stuck on one side.

Electronics workspace

Wire your board on a life-like breadboard or a schematic. Parts know their pins, drivers and supply voltage, and an electrical rules check warns before the magic smoke does.

Build your robot in 3‑D

Assemble a robot from blocks or STL meshes, join it with hinges and wheels, and pose it. Bind servos to joints, chain poses into walk cycles, and export clean URDF.

A bench of live instruments

Oscilloscope, multimeter, barometer, IMU, radar, servo, motor, data logger and more, fed live by a tiny library. watch() a sensor and the right one opens itself.

Offline simulated device

A real MicroPython interpreter compiled to WebAssembly. Run code, use the REPL and watch the instruments and 3-D model move with no hardware plugged in.

Boards, firmware and files

Raw-REPL over USB, file sync on every save, and one-click firmware flashing for RP2040, ESP32 and micro:bit. The Board Finder knows every board MicroPython builds for.

Learn as you go

Guided courses in the app, from your first blocks to a robot in 3-D, plus a ready-made servo-arm demo that shows the same robot in every workspace.

Fits any screenNEW

On small laptops, tablets and phones the editor takes the width, and the console, board and instruments share a pull-up sheet. Wiring works by touch.

Runs in your browser

app.snakie.org installs as an offline app, connects to real boards over Web Serial and can flash ESP32s. Great for Chromebooks and classrooms.

Git and GitHub built in

Stage, diff, commit and switch branches without leaving the editor, then publish a project to GitHub in one step. Export the whole project as a PDF when you need to share it.

Your work stays safeNEW

When a new version arrives, Snakie offers a restart instead of interrupting you, and every open tab comes back afterwards, unsaved changes and all.

Four workspaces, one project

The same robot, from every angle.

Switch workspace from the top of the window. Each one is a different view of the same project: the program, the circuit and the machine stay in step.

Blocks · Code

Drag blocks, read the Python.

Put Blocks and Code side by side and the two panes show the same program twice. Click a line to find its block. Hardware, instruments, your parts and your plugins all have blocks, and anything without one still round-trips safely.

  • Python to blocks: open any file and see it as blocks
  • Simple and advanced toolboxes, plus a turtle that draws
  • “What block is this?” help on every block
Code

An editor that has read the docs.

Snakie's Monaco editor reads the official MicroPython stubs, so it suggests what your board can actually do. Type pwm.duty_u16( and the parameters appear with the current one highlighted; hover a name for its signature and docs.

  • Follows your variables, imports and aliases
  • RP2 and ESP32 port-only API labelled
  • Linting with quick-fixes, outline and right-click help
Electronics

Wire it up before you plug it in.

Drop parts from the Standard library onto a breadboard and drag wires pin to pin. Snakie routes and colours them, checks the circuit, and installs each part's drivers onto the board.

  • Breadboard and schematic views, light, dark or blueprint
  • A growing Standard library of boards and parts, plus a Part Editor
  • Bill of materials, pinout tables and image export
Build

Then watch the robot move.

Model the robot from primitive blocks or your own STL and DAE meshes, join the parts, and bind each servo to its joint. Run your program and the 3-D model moves with it, on the simulator or a real board.

  • Hinge, slider and wheel joints, IK chains and a pose tool
  • Motion Studio: poses, walk cycles and puppet sliders
  • Mass, centre of mass and URDF import and export
Small screens

Code on the bus. Wire it on the iPad.

Below laptop width Snakie puts the editor first. The console, board and instruments share one pull-up sheet, a mini board floats over your code, and the whole thing works by touch, in the browser at app.snakie.org.

Instruments

Turn your program into a bench of instruments.

A handful of calls in your MicroPython code stream live values to on-screen instruments: an oscilloscope, an antique barometer, a 3-D IMU with compass, a multimeter, plotter, data logger and more. No probes, no extra hardware. Better still, watch() a sensor object and the right instrument lights up by itself.

# stream live values to Snakie's instruments
scope(adc.read_u16()) # → Oscilloscope
env(temp, pressure, humidity) # → Barometer
watch(imu=sensor) # → IMU (auto-detected)

Download & install

Up and running in a couple of minutes.

Grab the latest installer for your platform from GitHub Releases, or use the one-line installer. Snakie keeps itself up to date after that.

Don't want to install anything? Snakie runs in your browser, so it's great for Chromebooks and classrooms. Write and run MicroPython on the simulator, connect a real board over Web Serial (Chrome and Edge), and build robots in 3-D. Open app.snakie.org ↗

⚡ Quick install for macOS and Linux (including Raspberry Pi)

terminal
$ curl -sSL https://snakie.org/install.sh | bash

Detects your OS and CPU and installs the matching build. On Linux and Raspberry Pi it also adds Snakie to the Programming menu. For a system-wide install, pipe to sudo bash instead.

Prefer to build it yourself?

Snakie is open source and built with electron-vite. Clone the repo, install the dependencies and you're running a hot-reloading dev build. npm run dist packages an installer for your OS.

terminal
$ git clone https://github.com/kevinmcaleer/Snakie
$ cd Snakie
$ npm install
$ npm run dev    # hot-reload dev app
$ npm run dist   # build an installer
