Everything in Snakie · v{{ site.snakie_version }}

Every feature, from the headline acts to the small comforts.

Snakie is a complete MicroPython workbench in four workspaces: Blocks, Code, Electronics and Build. Write a program, wire the circuit, assemble the robot in 3-D and watch it run on live instruments, on a real board or entirely offline. Here's the full list, flagship features first.

Flagship features

The things that make Snakie different from every other MicroPython editor.

Blocks and Code, side by sideNEW

Blockly blocks and the MicroPython they write, in one split view. Snakie reads your existing Python back into blocks, with simple and advanced toolboxes and blocks for hardware, instruments, your parts and your plugins.

Autocomplete that knows MicroPythonNEW

Completions, parameter hints and hover docs from the official MicroPython stubs. It follows your variables and imports, and labels RP2-only and ESP32-only API.

Offline simulated device

A real MicroPython interpreter compiled to WebAssembly. The REPL and Run button actually execute Python, and the instruments and 3-D model still move.

Electronics workspace

Breadboard and schematic views with life-like parts and auto-routed wires. Snakie reads your code and wires every Pin(), I2C(), PWM() and ADC() to the pin it drives.

Electrical rules check

Warnings for parts on the wrong supply, power LEDs that only light when a part really has power, and a node-voltage overlay. Catch it before the magic smoke.

Parts Library & Part Editor

A portable, community parts library with a visual editor: pins, pads, connectors, internal wiring, I²C addresses, drivers and a 3-D mesh per part.

Build workspace (3‑D)

Build a robot from primitive blocks or STL/DAE meshes, join the parts with hinge, slider and wheel joints, and pose it. Bone mode and an IK goal gizmo for limbs.

Motion Studio

Save poses, chain them into walk cycles with per-step timing, and blend them with puppet sliders, driving the 3-D model live and the real servos when a board is connected.

Servo ↔ joint binding

Wire a servo, bind it to a joint and calibrate it. A running program's servo writes move the matching joint, and the Poses bench tests every pose live.

Mass & balance

Parts carry real mass. See per-link and total mass, the centre of mass and the support polygon, and read or write URDF <inertial> data.

On-screen instruments

Oscilloscope, barometer, multimeter, plotter, data logger, motor, bench PSU and more, fed live by a tiny telemetry library. watch() a sensor and the right one opens.

Learn in the app

Guided courses (Blocks to Python, First Steps, a robot on the breadboard, a robot in 3-D), shareable lesson links and a ready-to-run servo-arm demo project.

Small screens & touchNEW

Below laptop width the editor fills the screen and Console, Board and Instruments share a pull-up sheet, with a floating mini board. Wiring works by touch on an iPad.

Snakie in the browser

app.snakie.org is an installable, offline-capable web app: Web Serial for real boards, ESP32 flashing, the parts library and Build mode.

Board Finder & firmware

Browse every board MicroPython builds for, then flash MicroPython or CircuitPython to RP2040, ESP32 and micro:bit straight from the IDE.

Friendly snakie module

Write board code the clear way: from snakie import Servo, Buzzer, Led, Pin, PWM. One collision-proof name, so a vendor module can’t shadow yours.

Python plugin system

Extend Snakie with Python plugins (linters, commands, panels and blocks) without touching a line of TypeScript.

AI assist

A chat that sees your code and board setup, inline ghost-text suggestions and one-click apply, with Claude, OpenAI, Gemini, Copilot or Grok.

Git, GitHub & PDF export

Built-in source control, publish a project to GitHub in one step, and export the whole project (code, wiring, BOM) as a PDF.

Code embeds for tutorialsNEW

Embed a gist or repo file in any web page with Snakie's editor, Blocks view and a REPL that runs in the reader's browser, with an Open in Snakie button.

Snakie Flat designNEW

A calm, flat interface in light and dark: solid fills, hairline borders, Plus Jakarta Sans and IBM Plex Mono, with green for go and amber for the current mode.

The instrument bench

Live instruments, every one shown here running on Snakie's offline simulated device with no hardware attached. watch() a sensor and the right panel opens itself.

Quality of life

The hundred small touches that make a long session pleasant.

  • Updating keeps your work — Snakie suggests a restart when a new version lands, then reopens every tab, unsaved changes included.
  • Crash-safe file recovery — your open files come back on launch, even after a crash.
  • Keyboard shortcut cheatsheet — generated from the real bindings, so it's never out of date.
  • Real menus — File, Device, Tools and Help menus, plus ⌘S / Ctrl+S from anywhere.
  • File sizes & sync indicator — sizes in both file trees and a status-bar list of what's synced.
  • Status-bar history and tips — past messages are kept, and discovery tips teach you the app as you go.
  • Tidy-up suggestions — right-click your code and Snakie offers refactors, and explains why.
  • Sprite editor — draw sprites for LED matrices and OLEDs; a sprite in your code draws itself in the line.
  • Monaco editor — VS Code's engine with MicroPython highlighting, autocomplete and inline error squiggles.
  • Find & Replace with regex — case-sensitive, whole-word and regex toggles with a live match count.
  • Multi-file tabbed editing — work across files with tabs and keyboard shortcuts.
  • YAML/JSON validation — automatic checks with one-click formatting and repair.
  • Part version auto-bump — saving a part increments its patch version for easy update tracking.
  • Undo/redo in the Part Editor — a full history for pins, shapes, text, drag, rotate and delete.
  • Copy/paste style — reuse colours, fonts and borders across Part Editor elements.
  • Accessibility — screen-reader support, visible keyboard focus and a reduced-motion mode.
  • Customisable editor paper — ruled lines, grid dots or plain, with line spacing to taste.
  • Multiple AI providers — Claude, OpenAI, Gemini, Copilot or Grok with secure per-provider keys.
  • Inline AI autocomplete — ghost-text suggestions as you type.
  • Send console to chat — attach REPL output to an AI conversation for instant debugging.
  • Resizable file-panel split — drag the divide between local and device file trees.
  • Module manager — install only the device drivers your project actually uses.
  • One-click library updates — detect and update parts libraries instantly.
  • Native window chrome — Board View and Find & Replace use real OS title bars and window menus.
  • Floating project browser — a collapsible part hierarchy keeps the wiring canvas clear.
  • Export board as image — PNG, SVG or PDF at 1:1 scale for docs and sharing.
  • Duplicate parts — copy a placed part with a fresh id and an offset.
  • Firmware update check — automatic detection of newer firmware with one-click flash.
  • Smart alignment guides — centre-line snapping keeps designs tidy while dragging.
  • Multi-select & align toolbar — align and distribute several shapes or pins at once.
  • Styled text in the Part Editor — bold, italic, underline, colour and alignment.
  • Corner-radius control — sharp to fully-rounded rectangles.
  • GPU rendering toggle — software rendering on Raspberry Pi for extra stability.
  • Cross-platform builds — Windows, macOS (Intel & Apple Silicon), Linux x64 and Raspberry Pi.
  • In-app updates — background checks with one-click download and install.
  • Reopen last folder — your last project is restored on launch.
  • Docstring tooltips — hover items in the outline to read their docstrings.
  • Buy-me-a-coffee link — a subtle way to support development from the status bar.

Core features

Everything you'd expect from a serious MicroPython IDE, grouped by what you're doing.

Editor & files
  • Python code editor — highlighting, indent guides and code folding.
  • MicroPython-aware autocomplete — completions, parameter hints and hover docs from the official MicroPython stubs, with RP2/ESP32-only API labelled.
  • Compile to .mpy — right-click a .py to compile it, and click a .mpy to see what is inside.
  • Device file management — multi-select, drag files into folders, and delete right on the connected board.
  • Local file browser — create, rename, delete and organise files, Thonny-style.
  • Code outline — navigate functions, classes and definitions.
  • Variables inspector — watch locals during REPL sessions.
  • Code linting — ruff (or pyflakes) with quick-fixes.
  • Problems panel — one place for lint, syntax and config errors.
  • Context-sensitive help — right-click any keyword, type, built-in or library part for the reference article.
Device, REPL & firmware
  • Serial connection — raw-REPL over USB.
  • Interactive REPL shell — test and debug live.
  • Run, Stop & soft-reset — execute or interrupt with one click.
  • Serial plotter — graph numbers your code prints.
  • Package install (mip) — pull MicroPython packages onto the board.
  • Firmware flashing — UF2 for RP2040, esptool for ESP32.
  • Board Finder — a gallery of every board MicroPython builds for, with sizes and memory, feeding the firmware picker.
  • MicroPython or CircuitPython — choose which Python to flash; Modules, Packages and blocks follow the board.
  • Firmware modules detected — Snakie sees the modules baked into a board's firmware.
  • Telemetry library — one-line scope/meter/plot helpers.
  • Bidirectional control channel — the IDE commands a running program without interrupting it.
Instruments & panels
  • Oscilloscope — live PWM waveform with frequency & duty.
  • Multimeter & potentiometer — voltage min/max/avg, and a vintage ammeter dial.
  • Barometer — antique aneroid dial for temperature, pressure & humidity (BME280).
  • Plotter — multi-series graphing with auto-scaling and legend.
  • Range / radar — distance gauge and polar sweep.
  • Poses bench — a live test bench for a rig's servos: press a saved pose or drag a per-servo slider and the 3-D model (and the real servos) follow.
  • IMU 3D viewer & compass — roll/pitch/yaw with a horizon, plus a magnetometer heading.
  • Auto-detected instruments — watch() a sensor object and the right panel opens by itself.
  • Button & LED panels — monitor inputs, drive digital/PWM/RGB outputs.
  • NeoPixel control — colour-pick WS2812 strips.
  • Encoder panel — position dial, RPM and push-switch.
  • I²C display mirror — view SSD1306/SH1106/HD44780 from the IDE.
  • Interactive I²C scanner — an animated sweep, then click a found address to identify it and add the matching part.
  • Wi-Fi & Bluetooth scanners — live network and device discovery.
  • Buzzer & melody sequencer — RTTTL playback and a drag-to-compose staff.
  • Pop-out instruments — undock any panel into its own resizable OS window.
  • One-click on-device library — Snakie installs its tiny MicroPython runtime to the board for you, with a friendly from snakie import Servo, Buzzer, Led, Pin, PWM import for the hardware classes.
Electronics, parts & wiring
  • Mini board & Electronics workspace — a just-your-pins preview beside your code, and the full wiring canvas.
  • Many built-in boards — Pico, Pico 2 W, ESP32, Pimoroni Pico Plus 2, Tiny 2040 & Tiny 2350.
  • Custom board definitions — add your own boards.
  • Breadboard, schematic & node-graph views — life-like wiring, named I²C/SPI bus stubs, and auto-routed diagrams.
  • Breadboard themes — dark, light or a classic blueprint backdrop.
  • Live pin values — real GPIO state, PWM duty and activity on the board.
  • Drag parts onto the breadboard — pull from the library straight to where you want them.
  • Place, rotate, rename & per-part help — arrange parts, with a Help button for each.
  • Wire creation & auto-routing — drag pin-to-pin; wires route and colour-code themselves.
  • Connections table — edit every net below the canvas.
  • 2.54 mm grid snap — precise placement with guides.
  • Castellation & pin capabilities — edge half-holes and PWM/ADC/I²C/SPI/UART tagging.
  • Growing Standard library — Pico family, Adafruit Feathers, BME280, ICM20948, HC-SR04, motors & more, with SemVer update checks.
  • One-click driver install — required drivers copy to the board when you place a part, or from the missing-library banner.
Project, export & version control
  • Git source control — status, stage, commit, push, pull, branch and diff.
  • Publish to GitHub — put a project on GitHub without leaving Snakie.
  • Project PDF export — the whole project, code, wiring and BOM, as one PDF.
  • Project metadata — name and description in robot.yml.
  • BOM export — a Bill of Materials in Markdown with quantities.
  • Pinouts export — a pin-assignment table in Markdown.
Offline simulator
  • Simulated device terminal — a full WASM MicroPython REPL with no hardware.
  • Simulated filesystem — an in-memory /lib for importing and testing modules.
  • Simulated telemetry — animated sensor/motion/button readings drive the instruments offline.
Blocks
  • Blocks-first or side by side — a Blocks workspace, or Blocks and Code split with a dot between them.
  • Python → blocks converter — functions, classes, decorators, try/with, async, comprehensions and more read back as blocks.
  • Escape hatches — a line with no block yet stays as a Python block, so nothing is ever impossible.
  • Hardware blocks — named pins, PWM, I²C buses and module objects, in MicroPython or CircuitPython.
  • Data blocks — lists, dictionaries, tuples, text, bytes and bit maths drawers.
  • Turtle — watch the turtle draw as your program runs.
  • “What block is this?” — drop any block on the help well to learn what it does.
  • Block shape — try all three Blockly geometries in Settings ▸ Appearance.
Build (3‑D) & motion
  • URDF robots — open, create and export URDF; link any URDF to the project.
  • Join tool — mate faces by their normals, snap to hole centres, set roll and limits.
  • Kinematic chain view — a node tree with a parent picker and Fusion-style properties.
  • Exploded view, nav cube & ortho/perspective — inspect the build from any angle.
  • IK — a shared IK solver, an on-device snakie_ik.py runtime and Capture Pose.
  • Timeline — keyframes, sequences and puppet controls, exported as plain MicroPython.
Web, tablets & phones
  • Installable web app — app.snakie.org works offline once installed.
  • Web Serial — connect a real board from Chrome or Edge.
  • Remembers your folder — the web app reopens your project across reloads.
  • Pull-up sheet — Console, Board and Instruments tabs below the editor on small screens.
  • Floating mini board — tap it for the Board tab, hold it to see pin labels.
  • Touch wiring — drag wires on the breadboard with a finger.
